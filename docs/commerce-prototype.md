# DJL 商城交互原型

这是本地演示，不是正式商城。商品、订单、推荐关系、收益和提现均为模拟；不请求真实支付、AI 推理或账户服务。

## 立即体验

无需安装整个仓库的依赖，只需要 Node.js：

```powershell
node scripts/preview-shop.mjs
```

打开 <http://127.0.0.1:5890/shop/index.html>。可用第二个参数指定其他端口。

- 搜索商品或选择分类，查看商品详情、加购和修改数量。
- 在购物车中体验模拟结账；不用填写真实地址或银行卡。
- 在“订单”查看模拟订单，刷新后仍保留。
- “图片找商品”支持选择、拖入或粘贴截图，框选物品后按实际像素对比本地商品图；结果不再固定为帆布包。可用四种商品示例分别体验，也可得到无匹配反馈。图片不上传、不写入存储。
- 商品可收藏；“我的”提供收藏与最近浏览入口，刷新仍保留。只保存本机商品 ID，不保存照片。
- 订单可“再次购买”：按当前价格与剩余库存加到购物车，缺货会提示，不直接付款。
- “我的”可复制邀请链接、查看示例收益并申请模拟提现；这里只冻结演示余额，不真实打款。
- 页脚可重置演示数据，只修改 `djl-shop-prototype-v1`，不清理 AI 的存储。

本地预览只监听本机，不是可供其他设备访问的已部署商城。复制的邀请链接同样是本机演示链接。

## DJL 中的入口

AI 主界面的 Search 与 Kanban 之间增加商城入口。Electron 通过固定 IPC 打开或聚焦独立窗口，不导航或重置 AI 聊天。商城独立 session 不携带 AI 的 preload、Node、本地 API 或浏览器凭据；外网请求、新窗口和下载关闭。

入口源码已接入，完整 DJL 的运行仍需按仓库 README 安装 Bun/依赖并启动桌面开发环境。独立静态预览并不等于完整 Electron 已经构建或打包。

## 后续拆成两个软件

商城的 HTML、CSS、脚本和商品素材都位于 `apps/web/public/shop/`，不导入 AI 聊天、项目、终端和本地后端模块。该目录可以独立托管，也可装入另一套桌面或移动外壳；目前不包含独立安装包。

云端测试商城、供应商和管理端现已增加独立接口和数据表，详见 `docs/commerce-development.md`。正式资金、运行部署和跨设备验收仍未完成。不能把当前 localStorage 演示账本直接当作生产钱包。现有 AI 功能及其积分与商城分开。

正式推荐规则：所有普通用户可推荐；首单成功付款前确认唯一推荐人，绑定后后续有效购买持续计佣，仅直接推荐人获得收益。不做开店、多层抽成或自购返佣。当前原型只展示和说明规则，不建立真实用户关系。
