# DJL AI Writing Check

AI Writing Check is a private, local Work tool for English and Simplified Chinese prose. Open **Work → AI Writing Check**, paste text or choose TXT, DOCX, or a text-based PDF, install the needed local model once, and select **Analyze writing**.

When analyzable prose is present, the three percentages cover eligible prose and total 100%. When everything is excluded or uses an unsupported language, DJL abstains and does not present artificial percentages. Quotes, code, tables, references, headings/metadata, short list fragments, unsupported languages, and unreadable document content are reported separately as excluded. Passage highlighting shows what contributed to the result.

The result is an estimate, not proof of authorship. Do not use it as the sole basis for academic, employment, disciplinary, legal, or other consequential decisions. Short, heavily edited, translated, domain-specific, mixed-author, and adversarial text can be misclassified.

Model files are downloaded only when the user installs them. After installation, analysis works offline. The document itself is never sent to the model host.
