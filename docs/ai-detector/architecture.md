# Architecture

The React Work route uses typed WebSocket RPC for model state/install/remove/cache operations and an authenticated loopback HTTP request for document analysis. The HTTP response is NDJSON so extraction, routing, passage inference, and aggregation progress can render as it happens and cancellation can terminate request-scoped work.

The server reuses Work's bounded TXT/DOCX/PDF extraction. It normalizes grapheme clusters with stable offsets, routes paragraphs and same-line mixed-language sentences to English or Simplified Chinese, marks exclusions, and creates deterministic overlapping passages that are checked against the installed tokenizer before inference. Language-specific local ONNX classifiers calibrate probabilities into three bands and aggregate non-overlapping intervals by unique eligible characters. Largest-remainder rounding guarantees a 100% total whenever eligible prose exists; zero-coverage reports abstain.

`AiDetectorManager` owns lifecycle, concurrent request coordination, cancellation, and analysis. `DetectorModelRuntime` is lazy and local-only, caches lightweight tokenizers, and serializes native inference so language switches cannot dispose an active session. `modelInstaller` owns the only detector network path and uses bounded downloads, final checksum verification, durable staged files, rollback-safe promotion, and restart recovery. `DetectorResultCache` stores only content hashes and validated derived metadata; cache identities cover every model, tokenizer, and config artifact. Shared schemas in `packages/contracts/src/aiDetector.ts` prevent server/web result drift.
