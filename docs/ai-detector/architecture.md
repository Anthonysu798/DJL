# Architecture

The React Work route uses typed WebSocket RPC for model state/install/remove/cache operations and an authenticated loopback HTTP request for document analysis. The HTTP response is NDJSON so extraction, routing, passage inference, and aggregation progress can render as it happens and cancellation can terminate request-scoped work.

The server reuses Work's bounded TXT/DOCX/PDF extraction. It normalizes grapheme clusters with stable offsets, routes paragraphs and same-line mixed-language sentences to English or Simplified Chinese, marks exclusions, and creates deterministic overlapping passages that are checked against the installed tokenizer before inference. Language- and eligible-length-specific calibration maps local ONNX classifier scores into three bands and aggregates non-overlapping intervals by unique eligible characters. The calibration call requires the eligible-character count for that language; a language with fewer than 120 eligible characters remains uncertain even when a mixed-language document has at least 120 eligible characters overall. Largest-remainder rounding guarantees a 100% total whenever eligible prose exists; zero-coverage reports abstain.

`AiDetectorManager` owns lifecycle, concurrent request coordination, cancellation, and analysis. `DetectorModelRuntime` is lazy and local-only, loads the tokenizer and sequence-classification model directly, and serializes native inference so language switches cannot dispose an active session. Each model manifest declares an explicit output contract: either two logits with the AI label index and stable softmax, or one logit with stable sigmoid. The runtime reads raw logits, validates their shape, floating-point type, and finiteness, then applies only the declared conversion; the output contract is also part of the result-cache identity. `modelInstaller` owns the only detector network path and uses bounded downloads, final checksum verification, durable staged files, rollback-safe promotion, and restart recovery. `DetectorResultCache` stores only content hashes and validated derived metadata; cache identities cover every model, tokenizer, and config artifact and include the complete calibration-band bounds and thresholds directly, not only a calibration version label. Shared schemas in `packages/contracts/src/aiDetector.ts` prevent server/web result drift.
