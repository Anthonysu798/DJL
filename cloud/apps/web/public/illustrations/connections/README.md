# Connection illustrations

Two original transparent PNG illustrations generated with the built-in imagegen tool on 2026-10-27. Alpha was checked: both PNGs have transparent pixels and alpha spanning 0–254. No opaque background was added and no background-removal script was used.

- `device-connection-v2.png`: titanium laptop and phone connected by a frosted lavender ribbon.
- `social-connection-v2.png`: interlocking platinum and lavender-glass links.

Generated artwork contains no brand logos, badges, text or checkmarks. The consuming React component renders DJL's existing logo and Tabler's `IconBrandInstagram` / `IconBrandTiktok` separately. Tabler source: https://github.com/tabler/tabler-icons; MIT license: https://tabler.io/license. Brand icons are supplied by the declared `@tabler/icons-react` dependency, not hand-drawn approximations.

The full generation prompts and original output paths are recorded in `output/connection-redesign-2026-10-27/illustrations/prompts.json`.
