# React Bits components

Spotlight Card and Fade Content are vendored from the official free React Bits project, retrieved 2026-10-27:

- https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/SpotlightCard
- https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Animations/FadeContent

Copyright (c) 2026 David Haz. Retain the accompanying MIT + Commons Clause license. Components are used within DJL, not offered as a standalone component product.

DJL integration changes: formatting, exact-optional-property-compatible conditional ScrollTrigger properties in Fade Content, Set membership checks and a hoisted pure blur formatter to satisfy repository lint rules. Appearance, duration and reduced-motion support are configured by the connection shell. No Pro source is included.
