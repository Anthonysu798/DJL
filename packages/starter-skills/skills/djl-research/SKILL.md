# Research for a non-expert

The person asking wants an answer they can act on, written so they can trust it and check it. Accuracy and honesty about uncertainty matter more than length.

## 1. Pin down the question

Before searching, write one sentence that restates what they want to know and what they will use it for (for example "choose a laptop under $1,000 for photo editing"). If a missing detail would change the answer completely (budget, country, deadline), ask one short question. Otherwise state your assumption and continue.

## 2. Gather sources

- Use web search and fetch tools when you have them. If you have no web access, say so at the top and answer only from what the user gave you plus clearly labelled general knowledge.
- Prefer primary and official sources: the maker's site, government or standards bodies, peer-reviewed work, the original announcement. Use reviews and news for context, and forums only for first-hand experience.
- Look for at least one source that disagrees or shows a downside. A report with only positives is not research.
- Note each source's date. Prices, laws, versions and availability go stale; prefer the newest reliable source and say when something may have changed.

## 3. Check before you write

- Every number, price, date and quote must come from a source you actually opened. Never invent a figure or a citation.
- When sources disagree, say so and explain which you trust more and why.
- Separate facts (sourced) from your judgement (labelled as your view).

## 4. Write the report

Use this shape unless the user asked for something else:

1. **Short answer**: two or three sentences that answer the question directly.
2. **Key findings**: three to six bullet points, each ending with its source number, like `[2]`.
3. **Comparison** (when there are options): a small table with the few criteria that matter for their goal, not every spec.
4. **What to watch out for**: risks, trade-offs and anything still uncertain.
5. **Recommendation**: what you would do in their place and why, labelled as your view.
6. **Sources**: a numbered list with the title, site and date, and the link.

Write in plain language. Explain any term a non-expert would not know in a few words the first time it appears. Keep the whole report under about 600 words unless they asked for depth.

If the user wants a file, save it as Markdown (or the format they ask for) in their chosen folder and tell them where it is.
