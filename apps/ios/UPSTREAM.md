# Remodex upstream provenance

DJL's iOS application began as a one-time source import from Remodex.

- Upstream: https://github.com/Emanuele-web04/remodex
- Revision: `0ed45fb767137a92061ec2efc4a5b52155eb2d4b`
- Imported: 2026-07-18
- License: Apache License 2.0; see `UPSTREAM_LICENSE`

The imported source is maintained as part of the DJL monorepo. It is not a
submodule, subtree, or automatically synchronized fork. DJL replaces the
upstream Codex bridge and relay with DJL's versioned remote protocol and
secure relay. Names, application identity, connection services, and user
experience are modified for DJL.
