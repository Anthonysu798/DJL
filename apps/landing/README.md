# DJL_landing_website

Landing site for **DJL** — a local-first, bilingual (EN / 中文) agent command center.

Built with [Next.js](https://nextjs.org) (App Router), Tailwind CSS v4, GSAP, Motion, and a Spline 3D hero.

## Experience highlights

- Bilingual English and Chinese content throughout the interface.
- Cinematic motion, interactive lighting, and a real-time command-center aesthetic.
- Responsive layouts designed for desktop and mobile visitors.
- Production deployments automatically published from the `main` branch.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Deployed on [Vercel](https://vercel.com). Pushing to `main` triggers a production deploy.
