# Prototype product imagery

`products.png` was generated with the built-in image generation tool for this prototype. It is not a supplier's actual product catalog. The four equal quadrants are tote bag, lamp, travel tumbler, and desktop organizer; CSS selects each quadrant without remote assets.

Generation prompt: a square, seamless 2×2 product photography contact sheet with exactly four equal tiles, no text, borders, logos or watermarks; cream canvas tote bag top-left, minimal white desk lamp top-right, cream/stainless insulated tumbler bottom-left, bamboo desktop organizer bottom-right; cohesive light warm beige studio backgrounds, soft natural daylight, each product fully within its own tile.
