# DJL stats worker

This Cloudflare Worker counts two things and nothing else: clicks on the landing site's Download
buttons, and unique desktop installs. Both are stored in a D1 database named `djl-stats`.

## What is stored

- `downloads`: timestamp, platform (`windows`/`mac`), CPU architecture, the mirror that served the
  file (`github`, `oss`, or `vps`), the visitor's country as reported by Vercel, and the version.
- `installs`: a random install ID generated by the desktop app on its first launch, the timestamp,
  app version, platform (`darwin`/`win32`), CPU architecture, update channel, and the country
  Cloudflare derives from the request.

No IP address, hostname, username, or project data is ever received or stored.

Deployed at `https://djl-stats.slcor.workers.dev` (D1 database `djl-stats`, account subdomain
`slcor.workers.dev`). The read token lives outside the repository.

## Endpoints

- `POST /v1/downloads` — called by the landing site's download routes.
- `POST /v1/installs` — called once by each desktop install. Retries are idempotent.
- `GET /v1/stats` — requires `Authorization: Bearer <STATS_READ_TOKEN>`; returns totals and
  breakdowns by country, platform, source, version, and the last 30 days.

## One-time setup

From the repository root:

```sh
bunx --cwd apps/stats-worker wrangler d1 create djl-stats
```

Copy the printed `database_id` into `wrangler.jsonc`, then:

```sh
bunx --cwd apps/stats-worker wrangler d1 migrations apply djl-stats --remote
bunx --cwd apps/stats-worker wrangler secret put STATS_READ_TOKEN
bun run --cwd apps/stats-worker deploy
```

Then configure the two clients:

- Vercel project for the landing site: `DJL_STATS_URL=https://<worker host>` and, for the China
  mirror, `DJL_OSS_DOWNLOAD_BASE_URL=https://<bucket>.<region>.aliyuncs.com`. The bucket must hold
  each release's assets under `releases/v<version>/` with the same file names GitHub serves.
- GitHub repository variable `DJL_STATS_URL` with the same worker URL, so release builds bake it
  into the desktop app.

## Reading the numbers

```sh
curl -H "Authorization: Bearer $STATS_READ_TOKEN" https://<worker host>/v1/stats
```

or directly:

```sh
bunx --cwd apps/stats-worker wrangler d1 execute djl-stats --remote \
  --command "SELECT country, count(*) FROM installs GROUP BY country"
```

## Local development

bun run --cwd apps/stats-worker test
